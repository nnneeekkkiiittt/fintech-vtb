# ВТБ — конверты (frontend prototype)

Адаптивный интерфейс в сине-белой стилистике мобильного банковского приложения. Фронтенд связан с существующим Go API проекта `envelope-backend`.

## Запуск через Docker (Node.js/npm на компьютере не нужны)

1. Сначала запусти Go API и PostgreSQL в одном терминале:

   ```bash
   cd envelope-backend
   docker compose up --build -d
   ```

2. В другом терминале перейди в папку фронтенда и запусти контейнер:

   ```bash
   cd fintech-vtb-frontend
   docker compose up --build -d
   ```

3. Открой `http://localhost:5173`. Остановка фронтенда: `docker compose down` из папки `fintech-vtb-frontend`.

Docker собирает Vite-приложение в Node.js-образе, а пользователю отдаёт готовую статику через Nginx. Устанавливать Node.js или npm на хост не требуется. Nginx проксирует запросы `/api/` на Go API по адресу хоста `host.docker.internal:8080`, поэтому браузеру не нужно отдельно обращаться к порту 8080 и не возникает CORS-проблем. Go API должен быть опубликован на порту `8080`, как в текущем `envelope-backend/docker-compose.yml`.

Чтобы посмотреть интерфейс без запущенного API, можно собрать деморежим, изменив в `docker-compose.yml` аргумент `VITE_USE_MOCK_DATA` на `"true"`, затем пересобрать контейнер командой `docker compose up --build -d`.

## Поддерживаемые возможности

- загрузка конвертов и истории операций;
- создание, изменение и удаление конвертов согласно серверным ограничениям;
- настройка процентов распределения с проверкой суммы 100%;
- пополнение общего счёта с автоматическим распределением;
- запись расхода из выбранного конверта;
- просмотр, фильтрация и поиск истории, загрузка следующих страниц;
- мобильная нижняя навигация и адаптивная раскладка.

## Контракт API

Клиент использует реальные маршруты `/api/v1/envelopes`, `/api/v1/allocations`, `/api/v1/transactions`, `/api/v1/transactions/income` и `/api/v1/transactions/expense`. Денежные суммы преобразуются в копейки перед отправкой. Поле `data` в ответах API разворачивается на уровне адаптера `src/lib/api.ts`; React-компоненты работают с моделями из `src/lib/types.ts`.

Приложение учебное: оно не запрашивает банковские пароли и не подключается к реальным счетам ВТБ. Баланс на главном экране рассчитывается как сумма остатков конвертов, потому что отдельного баланса счёта в текущем API нет.
